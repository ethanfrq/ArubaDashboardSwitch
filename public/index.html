Installation à terminer

Voir la présentation (30 s)Ce que fait My Aruba Manager, en vidéo sans son, avant de terminer l’installation.

Le dashboard est en ligne, mais il lui manque encore des réglages sur Vercel. Suis les étapes ci-dessous, puis revérifie.

    Ajoute les variables manquantes

    1. Ouvre ton projet sur vercel.com, puis Settings et Environment Variables.
    2. Ajoute : le nom exact, une valeur à toi, pour tous les environnements (All Environments, ou au moins Production).
    3. Pour SESSION_SECRET et AGENT_TOKEN, colle une longue valeur aléatoire, générée par exemple avec :
    macOS ou Linux (Terminal) 
    openssl rand -base64 32
    Windows (PowerShell) 
    $b = New-Object byte[] 32; [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b); [Convert]::ToBase64String($b)

    Relie la base de données Supabase

    1. Dans ton projet Vercel, ouvre l’onglet Storage, puis Create Database et choisis Supabase.
    2. Garde le plan Free, choisis la région Paris (cdg1, eu-west-3), puis Connect pour ce projet.
    3. Vercel crée tout seul la variable POSTGRES_URL : rien à copier.
    1. La variable de la base existe, mais la base ne répond pas.
    2. Ouvre ton projet sur supabase.com : s’il est en pause, relance-le (Restore project).
    3. Sinon, dans l’onglet Storage de Vercel, vérifie que la base Supabase est bien connectée à ce projet.

    Redéploie le projet

    Dans Vercel : Deployments, le bouton du dernier déploiement, puis Redeploy. Les changements ne s’appliquent qu’au déploiement suivant (une minute environ).

    Rôles et droits

    Trois rôles, simples : choisis le plus petit qui suffit.

    Administrateur

    Tout, y compris les comptes.

    • Gérer les utilisateurs et leurs droits
    • Ports, VLAN, profils, actions planifiées
    • Console et commandes sensibles
    • Réglages, alertes, sauvegardes, annulation

    Technicien

    Agit sur les ports d’accès, pas sur la configuration.

    • Activer, couper, redémarrer un port
    • Description et VLAN d’un port
    • Tester les câbles, allumer des PC, ping
    • Nommer les appareils, plan de brassage
    • Non autorisé : Liens vers d’autres switches
    • Non autorisé : Console, réglages, comptes

    Lecture seule

    Regarde, ne touche à rien.

    • Tableau de bord, façade, alertes
    • Débit et historique
    • Non autorisé : Aucune action sur le switch
    • Non autorisé : Configuration complète masquée
